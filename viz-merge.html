Control Flow Merging

Path explosion in symbolic execution and how merging tames it  ·  OOPSLA 2026

In symbolic execution, every branch forks the engine: the true path and the false path are both explored independently. Inside a loop this causes exponential explosion — 2N paths after N iterations. Control-flow merging linearizes the loop body into a single combined block that computes both outcomes and picks the right one via a select, keeping a single symbolic state throughout.
